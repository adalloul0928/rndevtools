Supabase tab · static UI mockup

RN Devtools desktop · Simulator workspace · new Backend sidebar group · tool id supabase, ⌘8 (Settings moves to ⌘9). Final spec: native list/detail on the Lanes and Fleet console contract, attribution chain, phased P1 to P5. Every frame below is a fixed-size viewport; 1040×700 frames are the app’s minimum window (sidebar 225 px, content 815 × 652).

How to read it

  • Captions sit above each frame; the frame itself is the product surface.
  • P3 P4 P5 dashed tags and dashed boxes are mockup annotations (phase markers, variants). They are not product UI.
  • Frames marked P4 or P1 omit later-phase controls entirely (absent, not disabled).
  • Native confirmations are macOS message boxes drawn by main; renderer dialogs appear only to interrupt a live agent.

Data and secrets

  • Fake data only: ExampleApp, example.com, worktrees under ~/code/example-app-wt/, Metro ports 8100-8199, stack ports 20000-32767.
  • Keys never reach the renderer: the publishable key shows as sb_publishable_•••• and is copied by main.
  • No renderer copy contains the boundary-test tokens; command words come from main.
  • Fonts fall back to the system stack (Geist is not embedded).

What the mockup surfaced in the spec (details in the frame captions)

  • Five rows at 1040×700 do not quite fit. Measured in frame stacks-1040: 72 px header, 2 × 41 px notices, 108 px metrics, 51 px toolbar and 50 px activity leave 289 px for the list, about 4.5 rows of 64 px. The spec budgets 332 px. The MEMORY and DISK details wrap at this width (+22 px), and the view toggle’s 32 px buttons make the toolbar 51 px. With one-line details the list gets 311 px (4.9 rows).
  • Filter selects at 150 px clip their counts (“All stacks (10)”, “With backend (2)”), as Fleet’s do today. They need about 165 px, or a shorter label.
  • The four-button action row wraps to two lines in the 494 px detail. Each button keeps its full label.
  • Fleet list rows cannot take a third trailing chip below 1080 px. The wall (the default) wraps fine. The mockup moves the chips to line 2 (frame fleet-list-rows).
  • Choices the mockup made where the spec was silent or self-contradictory: the expanded notice toggle reads “Show fewer”. List rank treats only danger as “needs attention”, which matches the spec’s wireframe order. Release has no ellipsis for an abandoned holder (no prompt). The bulk “skips” line moves into the selection summary. Track repository… is icon-only below 1080 px. The unsupported state gets a short EmptyPanel. The policy dialog verbs are placeholders.
